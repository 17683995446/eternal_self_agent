# Eternal Self Agent

基于第一性原理的轻量化永动知识图谱 Agent — 零依赖、永久自治、自主进化。

## 核心公理

| 公理 | 定义 | 推导 |
|------|------|------|
| **存续公理 (Alive)** | 系统运行闭环永不终止，局部异常不能击穿整体 | 全局异常隔离、自愈重启、无限主循环 |
| **记忆公理 (Memory)** | 智能 = 结构化、可沉淀、可关联、可检索的历史经验 | 知识图谱作为唯一长期记忆载体 |
| **自驱公理 (Self-Drive)** | 无外部输入时自我产生任务、自我进化 | 知识关联自动推演新任务，实现永动 |

## 系统架构

```
┌─────────────────────────────────────────┐
│         自驱进化层 (evolve/)              │  ← 知识推演、权重迭代、自动精简
├─────────────────────────────────────────┤
│         知识记忆层 (kg/)                 │  ← 轻量化知识图谱核心
├─────────────────────────────────────────┤
│         任务队列层 (task/)               │  ← 有限队列、优先级调度
├─────────────────────────────────────────┤
│         存续保活层 (alive/)              │  ← 异常隔离、自愈、熔断
├─────────────────────────────────────────┤
│         基础核心层 (core/)               │  ← 常量、配置、日志、类型
└─────────────────────────────────────────┘
```

## 设计约束

1. **零外部服务依赖**: 无数据库、无 Redis、无 MQ、无 Neo4j
2. **全本地文件持久化**: 断电、重启、崩溃不丢失记忆
3. **无冗余逻辑**: 所有代码可被三大公理解释
4. **低资源稳态运行**: 空闲近乎零负载
5. **完全自闭环**: 无需人工干预

## 快速开始

```bash
# 安装
pip install -e ".[dev]"

# 启动
python -m eternal_self_agent.main

# 运行测试
pytest tests/ -v
```

## 配置

支持三种配置方式（优先级从高到低）:
1. 环境变量: `ETERNAL_LOOP_DELAY=0.5`
2. 配置文件: `data/config.json`
3. 代码默认值: `constants.py`
